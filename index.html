01 / EDGE AI
PROTOTYPE BUILT
EMBEDDED · EDGE AI · COMPUTER VISION

Offline Sign Language Recognition Using CNN

An edge-AI gesture recognition system: an ESP32-CAM (OV2640) captures 240×240 hand images and sends them over Wi-Fi (HTTP) to a Raspberry Pi 5, which runs an INT8-quantized TensorFlow Lite CNN locally with no cloud dependency. Achieves 94-95% test accuracy, showing the gesture and confidence score in about 2-3 s end-to-end.

02 / SPI
PROTOTYPE BUILT
EMBEDDED C · SPI · ACCESS CONTROL

RFID-Based Motor Control System

An Arduino UNO (ATmega328P, 16 MHz) controller using a 13.56 MHz MFRC522 reader over SPI to authenticate tag UIDs against 2 registered cards: one tag turns the motor ON, one turns it OFF, and all other UIDs are rejected. Switches a 9V motor through a 5V relay on GPIO D8, tested across a 3.3V / 5V / 9V circuit.

Arduino UNO MFRC522 SPI Relay Module

03 / IEEE PAPER
PROTOTYPE BUILT
EMBEDDED C · SENSOR INTERFACING

Smart Traffic Signal Controller

A 4-lane junction prototype on one Arduino UNO that uses IR and ultrasonic sensors to estimate lane density and adjust green-signal time. RF-based emergency detection overrides the cycle with an immediate green and buzzer alert, then restores normal operation. Documented in an IEEE-format paper with a 6-member team.
